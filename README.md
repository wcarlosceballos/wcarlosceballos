## 🛠️ Qué hago

**1. Formación profesional y educación digital**
Diseño instruccional por competencias (ADDIE + Matriz de Resultados), contenidos digitales,
plataformas LMS, estrategias de reskilling y upskilling, andragogía aplicada a entornos
virtuales.

**2. IA aplicada a problemas concretos**
Agentes de IA, prompting estructurado, Spec-Driven Development, sistemas multiagente,
automatización de procesos con criterio profesional.

**3. Software e ingeniería de requerimientos**
Aplicaciones web, análisis de datos (Python, SQL), levantamiento y validación de
requerimientos con stakeholders reales.
